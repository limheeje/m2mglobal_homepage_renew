M2M-eTrade 서비스 특징

M2M-eTrade 솔루션은 무역기반의 거래매칭 서비스를 지원하며, 거래 후 사후지원을 위한 해외결제, 국제물류를 지원합니다.​

  • 거래 매칭 지원
    • 상품관리/상품검색
    • 지역별 시장특성에 맞는 상품 전시
    • 자동번역 API
    • 거래협상 (대화형 인콰이러리)
  • 거래 및 사후 지원
    • 주문관리
    • 해외결제(Paypal, Escrow, Trade Assurance)
    • Worldwide Express DHL, EMS, CJ대한통운,판토스
    • 수출신고
    • 클레임관리
  • 활성화 부가서비스
    • Search Engine Optimization(SEO)화
    • 검색엔진마케팅
    • 상품연계 Open API (MakeGlob, BuyKorea)
    • 품키워드 추천 API
  • 전자무역 서비스
    • 신용장개설
    • 로컬L/C개설
    • 구매확인서
